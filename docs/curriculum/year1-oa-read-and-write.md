# Year 1 Phonics – 'oa' Read and Write

Source: school homework worksheet “'oa' Read and Write” (Twinkl). The child reads each
'oa' word, writes it under the matching picture, then reads it again to check.
The runtime copy of this content lives in `phonics/curriculum.js`
(term id `y1-oa`). Keep the two in sync — see “Adding a new term” in `CLAUDE.md`.

The sound is the long /oa/ as in *goat*. It is already on the Phase 3 tracker
(`oa` → goat, set `phase23`). This sheet adds words for reading and spelling it.

## 'oa' words — set id `y1-oa-words`

Every word is consonant + `oa` + consonant, so the words differ only in their first and
last letters (goat / boat / coat / moat). To tell them apart the child has to read the
whole word, not just spot the `oa`.

## Task breakdown

The worksheet asks for three things. Game 6, *Goat Boat* (`games/year1/goat-boat.js`),
practises the first two in turns:

1. **Read** the word and find its picture. In the game: a word is shown (not spoken)
   and the child taps the matching picture.
2. **Write** the word under the picture. In the game: a picture is shown and spoken, `oa`
   is already in place, and the child adds the other letters in order.
3. **Read it again to check.** In the game: after each answer the finished word is said
   aloud while it is highlighted.
