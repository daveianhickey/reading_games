# Year 1 Focus List – Weak Spots (from school, PhonicsTracker)

Source: two PhonicsTracker print-outs from school, showing the sounds and words the
learner is **not yet secure with**. Everything not on these sheets is treated as secure.
These are the **priority targets** for the Robot Stories (`docs/robot-stories-design.md`)
and can be used as a default selection in the Year 1 games.

Every item below already exists in `phonics/curriculum.js`, so no new items are needed.
Use the ids in the right-hand column (planned focus set id: `y1-focus`).

## How the stories use this list

- Each story picks **2–3 focus GPCs** and **5–8 focus HRSWs** and repeats each at least
  3 times across the story (spaced repetition inside one sitting).
- Every other word in a story must be *decodable* with Phase 2–5 GPCs he is secure with,
  or be a focus HRSW. A story test checks this (see the design doc).
- Robot names are built from focus GPCs so that reading the hero’s name is itself practice.
