# Year 1 Phonics – Common Exception Words

Source: Year 1 common exception words list given by the school.
The runtime copy lives in `phonics/curriculum.js` (term id `y1-common-exception`, set id `y1-cew`).

## Full list as given

the, put, of, to, go, into, pull, his, he, buses, we, me, be, push, was, her, my, you,
they, all, are, ball, tall, when, what, said, so, have, were, out, like, some, come,
there, little, one, do, children, love, oh, their, people, Mr, Mrs, your, ask, should,
would, could, asked

## Already in Autumn Term 1 (not repeated)

These 7 words are already in the Autumn 1 spelling set (`y1a1-spelling`, see
`year1-autumn-term-1.md`), so the app reuses those items:

`the`, `put`, `of`, `to`, `go`, `into`, `pull`
